How the radar prices a launch

Implied value = TVL × category multiple × momentum × maturity × breadth. The multiple is the median market-cap-to-TVL ratio of the protocols in the same category whose tokens already trade, computed from this snapshot (a thin category borrows its category group's median, then the global median). Momentum bends the price for the week's TVL change, maturity adds a small capped premium for each year a protocol has run with no token, and breadth adds a mild term for multi-chain reach. Tokened protocols are never ranked here: the board separates them out and uses them only as the pricing peers.

An implied value is this entry's own estimate from DefiLlama figures in the sealed snapshot. It is not a prediction that a token will launch, or when, or what it would trade at. A protocol shown as recording no token may still have one its record does not carry.
